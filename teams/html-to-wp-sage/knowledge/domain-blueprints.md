# پایگاه دانش: بلوپرینت ۲۰ حوزه‌ی کاری (Domain Blueprints)

> **منبع:** تصویر «طراحی سایت برای کسب‌وکار شما» (۲۰ کارت حوزه) — ایده‌ی پیش‌فرض برای هر نوع سایت.
> **نسخهٔ ماشین‌خوان (برای ایجنت‌ها):** [`../config/domain-blueprints.json`](../config/domain-blueprints.json)
>
> **قاعدهٔ ارجحیت:** **HTML منبع → بلوپرینت.** این نقشه/داده‌ها *پیش‌فرض*‌اند؛ هر جا HTML ورودی چیز
> دیگری گفت (بخش کمتر/بیشتر، متن متفاوت)، HTML برنده است و بلوپرینت فقط پرکننده‌ی جاهای خالی است.
>
> **چگونه استفاده می‌شود:**
> ۱. `TL` در INTAKE حوزه را از بریف شناسایی و بلوپرینت را بار می‌کند.
> ۲. `ARCH` در AUDIT نقشهٔ زیر را با HTML منبع تطبیق/تصحیح می‌کند → **نقشهٔ نهایی پروژه**.
> ۳. `CONV` content-manifest را از «بخش‌های خانه» + « Seeder» پیش‌پر و با متن واقعی HTML جایگزین می‌کند.
> ۴. `WP` از «Seeder» و «CPTها» ساختار داده را می‌سازد؛ `SEO` از «Schema/الگوی عنوان».

## ۱) شرکتی (`corporate`)
- **نقشه:** خانه · درباره ما · خدمات · نمونه‌کارها · وبلاگ · تماس
- **بخش‌های خانه:** hero+CTA → گرید خدمات → درباره با آمار → نمونه‌کارها → نظرات مشتریان → لوگوی مشتریان → CTA پایانی
- **CPT:** `service` (۸ رکورد)، `project`/نمونه‌کار (۶) — آمارها از **تنظیمات** نه هاردکد
- **تنظیمات:** تب هدر (لوگو/دکمهٔ CTA)، تب صفحات (فعال/ترتیب بخش‌ها)، تب فوتر (شبکه‌ها)
- **SEO:** `Organization` + `WebSite` · الگو: `{brand} نوین | {خدمات اصلی}`
- **بلورک‌ها:** hero، services-grid، stats-counter، portfolio-slider، logos-row، cta-band
- **نکته:** هیچ عدد/آماری هاردکد نشود — همه از پنل خوانده شود.

## ۲) آموزشی (`educational`)
- **نقشه:** خانه · درباره · دوره‌ها/کلاس‌ها · اخبار · تماس · سؤالات متداول
- **بخش‌های خانه:** hero → دسته‌های دوره → دوره‌های شاخص → اخبار → اساتید → آمار → CTA ثبت‌نام
- **CPT:** `course` (۸)، `teacher` (۵) — هر دوره: مدت، سطح، شهریه (قابل نمایش، فروش با woo در صورت نیاز)
- **SEO:** `EducationalOrganization` + `Course` · الگو: `{brand} نوین | آموزش {موضوع}`
- **بلورک‌ها:** hero، course-card، teacher-card، news-list، faq-accordion
- **نکته:** فرم ثبت‌نام با nonce؛ شهریه از دادهٔ دوره نه متن.

## ۳) فروشگاهی (`shop`) — ★ ووکامرس
- **نقشه:** خانه · فروشگاه · تک‌محصول · سبد · تسویه · درباره · تماس
- **بخش‌های خانه:** hero → دسته‌بندی محصولات → محصولات ویترین → محصولات تخفیف‌دار → وبلاگ → CTA
- **داده:** ** Seeder: ۱۲ محصول** با قیمت/موجودی/۲ تصویر/دسته (۴ دسته) — طبق `content-seeding.md`
- **اجبار:** overrideهای `woocommerce/` طبق `woocommerce-integration.md` — تک‌محصول/سبد/تسویه با طراحی HTML
- **تنظیمات:** تب «کنترل فروشگاه» (تعداد ستون/محصول، ویترین، تخفیف‌ها)
- **SEO:** `OnlineStore` + `Product` + `BreadcrumbList`
- **بلورک‌ها:** product-card، category-tile، price، add-to-cart، mini-cart

## ۴) پزشکی و کلینیک (`medical`)
- **نقشه:** خانه · درباره · خدمات درمانی · پزشکان · نوبت‌دهی · وبلاگ · تماس
- **بخش‌های خانه:** hero → خدمات → پزشکان → ویژگی‌های اعتماد → فرم نوبت‌دهی → مقالات → CTA
- **CPT:** `doctor` (۵: نام، تخصص، برنامهٔ حضور)، `treatment` (۸)
- **تنظیمات:** تب صفحات (انتخاب برگهٔ نوبت/تماس)، تب تماس (تلفن/آدرس/نقشه)
- **SEO:** `MedicalClinic` + `Physician` · الگو: `{brand} نوین | کلینیک {تخصص}`
- **بلورک‌ها:** hero، doctor-card، service-tile، appointment-form، trust-badges
- **نکته:** فرم نوبت‌دهی = فرم وردپرس امن (nonce + پیام فارسی)؛ ادعا/شعار درمانی ممنوع (محتوای واقعی).

## ۵) وکالت و دفتر حقوقی (`legal`)
- **نقشه:** خانه · درباره · حوزه‌های حقوقی · پرونده‌ها/مقالات · مقالات · تماس
- **بخش‌های خانه:** hero → حوزه‌های تخصصی → اعتماد+آمار → پرونده‌ها → مقالات → فرم مشاوره → CTA
- **CPT:** `practice` (۷ حوزه: خانواده، کیفری، تجاری…)، `case`/مقاله (۵)
- **SEO:** `LegalService` · الگو: `{brand} نوین | وکالت {تخصص}`
- **بلورک‌ها:** hero، practice-card، stats، article-card، consult-form
- **نکته:** رعایت شئون حرفه‌ای؛ نام وکلا و پروانه از دادهٔ واقعی پروژه.

## ۶) املاک (`realestate`)
- **نقشه:** خانه · فهرست املاک · تک‌ملک · درباره · تماس
- **بخش‌های خانه:** hero با جست‌وجو → دسته‌های ملک → املاک ویترین → خدمات → فرم مشاوره → CTA
- **CPT:** `property` (**۱۲ ملک**: قیمت، متراژ، اتاق، منطقه) + taxonomy: نوع ملک (۴)، منطقه
- **بلورک‌ها:** hero-search، property-card، price-badge، filter-bar، map-embed
- **SEO:** `RealEstateAgent` + `Residence`
- **نکته:** فیلتر/جست‌وجو با کوئری تمیز؛ قیمت با `number_format` فارسی از داده.

## ۷) رستوران و کافه (`restaurant`)
- **نقشه:** خانه · منو · درباره · گالری · تماس · رزرو
- **بخش‌های خانه:** hero → منتخب منو → داستان → گالری → فرم رزرو → ساعت/نقشه → CTA
- **CPT:** `menu_item` (**۱۸ آیتم**: نام، قیمت، توضیح، تصویر، دسته) + `menu_category` (۴: پیش‌غذا، غذای اصلی، نوشیدنی، دسر)
- **SEO:** `Restaurant` + `Menu`
- **بلورک‌ها:** hero، menu-item-row (قیمت کنار نام)، gallery-masonry، reservation-form، hours-map
- **نکته:** قیمت‌ها از CPT؛ «ساعت کاری» از تنظیمات؛ بدون ووکامرس مگر HTML سفارش آنلاین داشت.

## ۸) هتل، ویلا و اقامتگاه (`hotel`)
- **نقشه:** خانه · اتاق‌ها/اقامتگاه‌ها · تک‌اتاق · رزرو · درباره · گالری · تماس
- **بخش‌های خانه:** hero → انواع اتاق → پیشنهادات → گالری → قوانین → موقعیت → فرم رزرو → CTA
- **CPT:** `room` (۸: ظرفیت، امکانات، قیمت شب)
- **بلورک‌ها:** hero، room-card، gallery، booking-form، amenities-icons
- **SEO:** `LodgingBusiness` + `HotelRoom`
- **نکته:** «ترکیبی»: فروش پکیج/بیعانه با woo فقط اگر HTML منبع داشت؛ رزرو = فرم.

## ۹) آژانس مسافرتی و گردشگری (`travel`)
- **نقشه:** خانه · تورها · تک‌تور · مقاصد · درباره · تماس · سؤالات متداول
- **بخش‌های خانه:** hero → تورهای پرتقاضا → مقاصد → چرا ما → گالری → فرم مشاوره → CTA
- **CPT:** `tour` (**۱۰ تور**: مقصد، مدت، قیمت، تاریخ)، `destination` (۸)
- **بلورک‌ها:** hero، tour-card، price-badge، destination-tile، faq-accordion
- **SEO:** `TravelAgency` + `TouristTrip`
- **نکته:** «ترکیبی»: فروش تور با woo در صورت پرداخت آنلاین HTML؛ وگرنه CPT + فرم رزرو.

## ۱۰) خبری و مجله اینترنتی (`news`)
- **نقشه:** خانه · دسته‌بندی · تک‌خبر · درباره · تماس
- **بخش‌های خانه:** نوار خبر متحرک → خبر اصلی → نوار دسته‌ها → آخرین اخبار → خبرنامه → پربازدیدها
- **داده:** **Seeder: ۲۵ مقاله/خبر** در ۶ دسته با تصویر شاخص و خلاصهٔ واقعی
- **SEO:** `NewsMediaOrganization` + `NewsArticle` · الگو: `{خبر} | {brand} نوین`
- **بلورک‌ها:** news-card، ticker، category-tabs، newsletter-form، popular-list
- **نکته:** `date_i18n` فارسی؛ سلسله‌مراتب H1 سخت‌گیرانه؛ سرعت (بدون JS سنگین).

## ۱۱) شخصی و رزومه (`personal`)
- **نقشه:** خانه · درباره · نمونه‌کارها · وبلاگ · تماس
- **بخش‌های خانه:** معرفی کوتاه → مهارت‌ها → تایم‌لاین تجربه → نمونه‌کارها → مقالات → فرم تماس
- **CPT:** `portfolio_item` (۸)
- **SEO:** `Person` + `ProfilePage` · الگو: `{نام} — {تخصص}`
- **بلورک‌ها:** hero، skill-bar، timeline، portfolio-grid، contact-form
- **نکته:** نام/رزومه/لینک‌ها از تنظیمات؛ عکس پرتره از رسانه.

## ۱۲) باشگاه ورزشی و بدنسازی (`fitness`)
- **نقشه:** خانه · کلاس‌ها · مربیان · پلن‌ها/اشتراک · درباره · گالری · تماس
- **بخش‌های خانه:** hero → کلاس‌ها → مربیان → پلن‌های قیمت → قبل/بعد → گالری → CTA عضویت
- **CPT:** `class` (۸)، `trainer` (۵)
- **بلورک‌ها:** hero، class-card، trainer-card، price-plan، gallery
- **SEO:** `SportsActivityLocation` + `Course`
- **نکته:** «ترکیبی»: فروش اشتراک با woo فقط اگر HTML پرداخت داشت؛ پلن‌ها در غیر این صورت از تنظیمات.

## ۱۳) صنعتی و کارخانه‌ای (`industrial`)
- **نقشه:** خانه · درباره · محصولات · تک‌محصول · کیفیت/استانداردها · پروژه‌ها · تماس
- **بخش‌های خانه:** hero → گرید محصولات → ظرفیت تولید → گواهینامه‌ها → پروژه‌ها → مشتریان → CTA
- **CPT:** `product_line` (۱۰)، `project` (۶)
- **بلورک‌ها:** hero، product-tile، cert-badges، stats، clients-logos
- **SEO:** `Manufacturer` + `Product`
- **نکته:** B2B: فرم استعلام/درخواست پیشنهاد قیمت؛ بدون ووکامرس (فاکتور/قرارداد).

## ۱۴) خدمات (`services`)
- **نقشه:** خانه · خدمات · تک‌خدمت · درباره · وبلاگ · تماس
- **بخش‌های خانه:** hero → گرید خدمات → مراحل کار → چرا ما → نظرات → مقالات → CTA
- **CPT:** `service` (**۱۰ خدمت** با قیمت/زمان تحویل در صورت نیاز)
- **SEO:** `Service` + `BreadcrumbList`
- **بلورک‌ها:** hero، service-card، steps، testimonials، cta-band
- **نکته:** عمومی‌ترین بلوپرینت — اگر حوزه دقیق نبود، از همین شروع می‌شود.

## ۱۵) مذهبی، فرهنگی و خیریه (`charity`)
- **نقشه:** خانه · درباره · فعالیت‌ها · کمک/کمک مالی · اخبار · تماس
- **بخش‌های خانه:** hero → فعالیت‌ها → آمار تأثیر → فرم کمک → اخبار → CTA داوطلبی
- **CPT:** `activity` (۸ پروژه/فعالیت)
- **SEO:** `NGO` + `Event`
- **بلورک‌ها:** hero، activity-card، stats، donation-form، news-list
- **نکته:** شفافیت مالی با دادهٔ واقعی؛ فرم کمک = درگاه واقعی یا راهنمای پرداخت (بدون درگاه جعلی).

## ۱۶) آموزشگاه و مؤسسه (`academy`)
- **نقشه:** خانه · دوره‌ها · تک‌دوره · مدرسین · درباره · تماس · ثبت‌نام
- **بخش‌های خانه:** hero → دسته‌های دوره → دوره‌های ویژه → مدرسین → فرم ثبت‌نام → گالری → CTA
- **CPT:** `course` (**۱۰ دوره** با شهریه/مدت/سطح)، `teacher` (۶)
- **بلورک‌ها:** hero، course-card، teacher-card، register-form، faq-accordion
- **SEO:** `EducationalOrganization` + `Course`
- **نکته:** تفاوت با «آموزشی»: فروش/ثبت‌نام دوره → «ترکیبی» (woo برای شهریه فقط اگر HTML پرداخت داشت).

## ۱۷) دکوراسیون و معماری (`architecture`)
- **نقشه:** خانه · پروژه‌ها · تک‌پروژه · خدمات · درباره · تماس
- **بخش‌های خانه:** hero → پروژه‌های شاخص → خدمات → فرآیند کار → قبل/بعد → نظرات → CTA
- **CPT:** `project` (۱۰: مساحت، سال، سبک)، `service` (۶)
- **بلورک‌ها:** hero، project-grid، before-after-slider، process-steps، cta
- **SEO:** `HomeAndConstructionBusiness`
- **نکته:** گالری سنگین → رعایت بودجهٔ `MEDIA` (hero ≤۱۰۰KB)؛ لود تنبل.

## ۱۸) تکنیک پیج و استارت‌آپ (`startup`)
- **نقشه:** خانه · امکانات · قیمت‌ها · وبلاگ · درباره · تماس
- **بخش‌های خانه:** hero محصول → امکانات → چطور کار می‌کند → نظرات → جدول قیمت → FAQ → CTA ثبت‌نام
- **داده:** ۶ صفحه + ۶ مقاله — بدون CPT اجباری
- **SEO:** `SoftwareApplication` + `Organization`
- **بلورک‌ها:** hero-app، feature-tile، pricing-table، testimonial-slider، faq-accordion
- **نکته:** «تکنیک پیج» = لندینگ محصول؛ تمرکز سرعت + CTA تک‌محور؛ قیمت‌ها از تنظیمات.

## ۱۹) کشاورزی و محصولات محلی (`agriculture`) — ★ ووکامرس
- **نقشه:** خانه · فروشگاه · تک‌محصول · سبد · تسویه · درباره · تماس
- **بخش‌های خانه:** hero → دسته‌های محصول → محصولات تازه → داستان مزرعه → کیفیت/گواهی → وبلاگ → CTA
- **داده:** **Seeder: ۱۲ محصول** (مثلاً عسل، زعفران، برنج، خرما…) با قیمت/تصویر/۴ دسته
- **اجبار:** overrideهای `woocommerce/` مثل حوزهٔ فروشگاهی
- **SEO:** `OnlineStore` + `Product` · الگو: `{brand} نوین | {محصول محلی} تازه`
- **بلورک‌ها:** product-card، category-tile، farm-story، price، add-to-cart
- **نکته:** «محلی/تازه/ارگانیک» فقط اگر واقعی باشد — ادعای تأییدیه‌ای بدون مدرک ممنوع.

## ۲۰) آرایشگاه و سالن زیبایی (`beauty`)
- **نقشه:** خانه · خدمات · گالری · رزرو · درباره · تماس
