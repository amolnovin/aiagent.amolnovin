# تیم ۵ نفره متخصص وردپرس - WP Elite Team

این تیم در همین چت برای شما ساخته شد. هر ۵ ایجنت فعال هستند و می‌توانید همین الان با آن‌ها کار کنید.

## لیست ایجنت‌ها

### 1. 🧩 کدکس - @codex - معمار افزونه
**تخصص:** ساخت افزونه از صفر تا انتشار در wordpress.org
- OOP, Namespace, Autoloader
- CPT, Settings API, REST API
- امنیت کامل

### 2. 🎨 تیموس - @themos - استاد قالب
**تخصص:** قالب‌های FSE مدرن و سبک
- theme.json, Patterns, Templates
- Tailwind CSS, Vite
- تبدیل Figma به WP

### 3. 🛒 ووگر - @wooger - ووکامرس
**تخصص:** فروشگاه ساز حرفه‌ای
- درگاه پرداخت ایرانی (زرین‌پال، زیبال)
- اشتراک، قسطی، چندفروشندگی
- HPOS سازگار

### 4. 🛡️ سکیورکس - @securx - امنیت و سرعت
**تخصص:** هاردنینگ و بهینه‌سازی
- رفع آسیب‌پذیری
- PageSpeed 100
- Redis, Query Monitor

### 5. ⚡ المنتورا - @elementora - فرانت‌اند
**تخصص:** المنتور و گوتنبرگ
- ویجت اختصاصی المنتور
- بلوک React گوتنبرگ
- UI/UX فارسی و RTL

## نحوه استفاده در همین چت

کافی است تگ ایجنت را بنویسید:

```
@codex یک افزونه رزرو نوبت با تقویم شمسی بساز

@themos یک قالب شرکتی مینیمال با Tailwind و FSE بساز

@wooger یک درگاه پرداخت قسطی برای ووکامرس بساز

@securx این کد افزونه من را بررسی امنیتی کن: [کد]

@elementora یک ویجت المنتور مقایسه قیمت مدرن بساز

@همه یک سایت فروشگاهی کامل با قالب و افزونه اختصاصی بسازید
```

## فایل‌ها
- `dashboard.html` -> پنل بصری تیم (همین را باز کنید)
- `agents/` -> پرامپت کامل هر ایجنت
- `config.json` -> تنظیمات تیم
