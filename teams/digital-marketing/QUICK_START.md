# راهنمای نصب 5 دقیقه‌ای — 10 ایجنت

## گام 1: انتخاب پلتفرم
- **ساده‌ترین:** ChatGPT (Custom GPTs) یا Claude Projects
- **حرفه‌ای:** n8n, Make, Flowise, LangChain

## گام 2: ساخت 10 ایجنت (کپی-پیست)
برای هر ایجنت (مثلا 01-strategist):
1. پوشه `agents/01-strategist/` را باز کن
2. `system_prompt.txt` را کپی کن
3. در پلتفرم مقصد یک Agent/GPT جدید بساز و در قسمت System Prompt پیست کن
4. `tasks.md` را به عنوان Knowledge/Source آپلود کن
5. تنظیمات `config.json` را اعمال کن (مدل، temperature)

> زمان تقریبی هر ایجنت: 30 ثانیه → کل پک: 5 دقیقه

## گام 3: تست
در هر ایجنت این را بفرست:
```
سلام، خودت را معرفی کن و بگو وظایف اصلی‌ات چیست؟
```

## گام 4: شخصی‌سازی برای کسب‌وکارت
در اولین پیام به هر ایجنت این را بگو:
```
کسب‌وکار من: [نام + حوزه + سایت + مخاطب هدف + بودجه ماهانه]
لطفا خروجی را برای من شخصی‌سازی کن.
```

## گام 5: اجرای کمپین اول
به ایجنت 01 بگو:
```
برای 90 روز آینده استراتژی کامل با بودجه [مبلغ] بساز و وظایف را بین بقیه ایجنت‌ها تقسیم کن.
```
سپس خروجی 01 را به ایجنت‌های 02 تا 10 بده.

## سوالات متداول

**آیا می‌توانم فقط 3 ایجنت را نصب کنم؟**
بله، با 01 + 02 + 03 شروع کن، بعد بقیه را اضافه کن.

**آیا به API نیاز دارم؟**
خیر، فقط کپی پرامپت کافی است. برای اتوماسیون حرفه‌ای (n8n) نیاز به API خواهی داشت.

**زبان پرامپت‌ها؟**
همه پرامپت‌ها فارسی هستند ولی خروجی را می‌توانی به انگلیسی/آلمانی هم بخواهی.
