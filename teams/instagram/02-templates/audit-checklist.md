# 🩻 چک‌لیست حسابرسی پیج (۷ بخش) — ایجنت دانیال + رادین

> هر مورد: ✅ سالم | ⚠️ نیاز به بهبود | ❌ بحرانی
> مسیر دسترسی در اپ نوشته شده تا خودتان هم بتوانید چک کنید.

---

## ۱. سلامت حساب و صلاحیت توصیه (بحرانی‌ترین بخش) ✅

- [ ] **Settings → Account Status** → وضعیت توصیه حساب پاک است؟
- [ ] پرچم «Not eligible for recommendation» وجود ندارد؟
- [ ] اگر محتوا flag شده: ویرایش/حذف/appeal انجام شد؟
- [ ] **Recommendations Guidelines** نقض نشده؟ (محتوای حساس، کاور نامناسب، ادعای درمانی/مالی)
- [ ] حساب از نوع **Professional (Creator یا Business)** است؟ (بدون آن Insights ندارید)
- [ ] وضعیت اصالت: چند درصد از پست‌های ۳۰ روز اخیر کاملاً اورجینال است؟ (قانون آوریل ۲۰۲۶) ✅
- [ ] واترمارک پلتفرم دیگر (TikTok/CapCut/…) روی ویدیوها نیست؟
- [ ] حساب محدود/Restricted نشده؟

## ۲. هویت پروفایل (اولین نقطه تبدیل)

- [ ] **نام پروفایل** شامل کلمه کلیدی اصلی است؟ (نه فقط اسم برند) — برای جستجوی داخل اپ ✅
- [ ] **handle** ساده، بدون عدد و آندرلاین اضافی
- [ ] **بیو** این چهار جزء را دارد: چه‌کار می‌کنم / برای چه کسی / اثبات یا عدد / CTA؟
- [ ] **کلمه کلیدی و موقعیت در بیو** (توصیه رسمی Instagram) ✅
- [ ] **لینک** فعال و درست است؟ (یا Linktree/لینک مستقیم)
- [ ] **دسته‌بندی (Category)** درست انتخاب شده؟
- [ ] **دکمه تماس/ایمیل/مسیر** فعال است؟ (برای Business)
- [ ] عکس پروفایل در اندازه کوچک خوانا است؟
- [ ] بیو زیر ۱۵۰ کاراکتر و قابل اسکن است؟

### فرمول بیو پیشنهادی
```
[نتیجه‌ای که می‌سازی] برای [مخاطب مشخص]
[اثبات: عدد / سال تجربه / تعداد مشتری]
[یک خط تمایز یا باور]
👇 [CTA مشخص]
```

## ۳. گرید و هایلایت‌ها

- [ ] سه پست اول گرید، پیام اصلی پیج را می‌رسانند؟
- [ ] کاور پست‌ها **متن خوانا** دارند (بسیاری بی‌صدا و سریع اسکرول می‌کنند)
- [ ] هایلایت‌ها دسته‌بندی شده‌اند: درباره ما / نتایج / سوالات / محصولات / پشت‌صحنه
- [ ] کاور هایلایت یکدست است؟
- [ ] هایلایت «نتایج/رضایت مشتری» وجود دارد؟ (اثبات اجتماعی = موتور فروش)
- [ ] پست‌های پین‌شده سه پست برتر هستند؟

## ۴. کیفیت و اصالت محتوا

- [ ] نسبت اورجینال به بازنشر در ۳۰ روز اخیر
- [ ] آیا «ارزش افزوده واقعی» به محتوای شخص ثالث اضافه شده؟ (واترمارک/کردیت کافی نیست) ✅
- [ ] کیفیت صدا قابل قبول است؟ (بدون نویز، بدون اکو)
- [ ] نور و کادربندی در حد قابل قبول است؟
- [ ] ریلزها **صدا/موزیک** دارند؟ (بدون صدا از توصیه خارج می‌شوند) 🔎
- [ ] نسبت ۹:۱۶ کامل رعایت شده (بدون نوار سیاه)؟
- [ ] زیرنویس/متن روی تصویر برای تماشای بی‌صدا هست؟

## ۵. اینستاگرام SEO و گوگل

- [ ] کلمه کلیدی اصلی در: نام پروفایل + بیو + خط اول کپشن‌ها ✅
- [ ] هشتگ‌ها حداکثر **۵ عدد** و کاملاً مرتبط هستند؟ ✅
- [ ] کلمه کلیدی در **کپشن** است، نه در کامنت ✅
- [ ] **Alt text** برای پست‌های تصویری نوشته شده؟
- [ ] لوکیشن برای کسب‌وکار محلی ثبت می‌شود؟
- [ ] تنظیم «Allow public photos and videos to appear in search engine results» آگاهانه انتخاب شده؟ (پیش‌فرض: فعال) ✅
- [ ] **Google Search Console** (platform property) وصل شده تا ببینید کدام کوئری‌های گوگل پست شما را نشان می‌دهند؟ ✅

## ۶. استراتژی و کدنسی

- [ ] کدنسی ۳۰ روز اخیر: چند پست در هفته؟ ثبات داشته؟
- [ ] توزیع فرمت: ریلز / کاروسل / تک‌عکس / استوری
- [ ] ستون‌های محتوا مشخص و قابل تفکیک‌اند؟ (برای Your Algorithm) ✅
- [ ] هر پست یک CTA مشخص دارد؟
- [ ] هوک ۳ ثانیه اول در ریلزها تست شده؟
- [ ] آیا از **Trial Reels** برای تست استفاده شده؟
- [ ] آیا محتوای «قابل ارسال در دایرکت» ساخته‌ایم؟ (قوی‌ترین سیگنال رشد) ✅

## ۷. تبدیل و تعامل (جایی که پول ساخته می‌شود)

- [ ] میانگین زمان پاسخ به دایرکت زیر ۲۴ ساعت است؟ ✅
- [ ] اسکریپت آماده پاسخ دایرکت دارید؟ (سلام/قیمت/مشاوره/اعتراض)
- [ ] استوری‌ها لینک استیکر و استیکر تعاملی دارند؟
- [ ] نظرسنجی/سوال در استوری استفاده می‌شود؟
- [ ] پاسخ به کامنت‌ها واقعی و چندکلمه‌ای است؟ (نه فقط ایموجی)
- [ ] UGC/رضایت مشتری بازنشر می‌شود؟
- [ ] مسیر خرید روشن است؟ (چند کلیک از پست تا پرداخت)
