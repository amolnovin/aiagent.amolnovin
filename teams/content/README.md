## 🚀 چطور استفاده کنم؟

### روش ۱ — استفاده تکی (ساده‌ترین)
فایل MD هر ایجنت را کپی کن و به‌عنوان **System Prompt** یا **Custom Instruction** در ابزار دلخواهت بچسبان. از آن‌جا به بعد، آن مدل دقیقاً همان متخصص است.

### روش ۲ — در پروژه‌ها (Claude Projects / ChatGPT GPTs / Cursor)
1. فایل‌های `agents/*.md` را به Knowledge/Context پروژه اضافه کن
2. این قانون را به آخر پیام سیستم اضافه کن:
> «با دیدن هر تریگر (`@آریا` `@نگار` `@کیان` `@ترانه` `@سارا` `@تیم`)، کاملاً در نقش همان ایجنت قرار بگیر و با نام و ایموجی‌اش پاسخ بده.»

### روش ۳ — برنامه‌نویسی (API)
از `manifest.json` به‌عنوان رجیستری استفاده کن: تریگرها را بنگار و محتوای MD ایجنت را به‌عنوان سیستم پرامپت بارگیری کن.

## 🎮 تریگرها (راهنمای سریع)

| دستور | کاری که می‌کند |
|---|---|
| `@آریا` | استراتژی، پرسونا، تقویم محتوایی، ایده‌پردازی |
| `@نگار` | مقاله، بلاگ، کپی تبلیغاتی، ایمیل فروش |
| `@کیان` | کلمات کلیدی، بریف سئو، متا تگ، ممیزی سئو |
| `@ترانه` | ویرایش چهارمرحله‌ای، فکت‌چک، تأیید انتشار |
| `@سارا` | کپشن، هشتگ، اسکریپت ریلز، پرامپت/تولید تصویر |
| `@تیم` | خط تولید کامل: استراتژی ← سئو ← نگارش ← ویرایش ← نسخه‌بندی |

### مثال آماده
```
@تیم — یک مقاله سئو شده درباره «۵ اشتباه رایج در بازاریابی محتوایی»
+ بسته کامل انتشار اینستاگرام و لینکدین برای آن آماده کنید
```

## 🔧 سفارشی‌سازی

- برای برند خودت، یک فایل `BRAND.md` به ریشه پکیج اضافه کن (صدای برند، مخاطب، محصولات) — ایجنت‌ها به آن ارجاع می‌دهند
- برای افزودن ایجنت ششم (مثلاً متخصص ایمیل‌مارکتینگ)، فایل جدید MD بساز و به `manifest.json` اضافه کن
- برای تغییر زبان پیش‌فرض، مقدار `default_language` در منیفست را تغییر بده

## 🇬🇧 English Summary

A pack of 5 specialized AI content-creation agents (Strategist, Copywriter, SEO, Editor, Social Media) as ready-to-use system prompts. Copy any agent's `.md` file as a system prompt in any LLM tool (ChatGPT, Claude, Gemini, Cursor...). Triggers (`@name`) switch personas. `manifest.json` provides a machine-readable registry; `workflows/team-pipeline.md` defines the full 5-step production pipeline. Default output language: Persian — change freely.
