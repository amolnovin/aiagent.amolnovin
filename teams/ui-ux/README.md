# تیم ۵ نفره ایجنت‌های فوق‌تخصص UI/UX

این پکیج یک تیم ۵ نفره از ایجنت‌های هوش مصنوعی است که با هم کار می‌کنند تا:

1. **۱۰ تا ۲۰ سایت مرجع** در حوزه کاری را بررسی و آنالیز کنند
2. **مشکلات UX/UI** آن‌ها را پیدا و اولویت‌بندی کنند
3. با استفاده از **جدیدترین روندهای طراحی ۲۰۲۶** (bento grid، glassmorphism کنترل‌شده، scroll-driven animation، parallax، view transitions، فونت متغیر) طرح‌های جدید بسازند
4. طرح‌ها را به صورت **HTML، CSS و JS ریسپانسیو** تحویل دهند

## نصب در سایت هوش مصنوعی (Arena)

1. فایل `agents.json` را باز کن. برای هر ایجنت فیلد `system_prompt` را کپی کن.
2. در بخش تنظیمات ایجنت/دستیار سفارشی پلتفرم، یک ایجنت جدید بساز، نام آن را از فیلد `name_fa` بگذار و `system_prompt` را در فیلد دستورالعمل (System Prompt) قرار بده.
3. برای هر ایجنت، محتوای فایل `agents/0X_*.md` مربوط را هم به عنوان **دانش مرجع** (Knowledge / فایل پیوست) اضافه کن. این فایل‌ها playbook کامل هر ایجنت هستند.
4. فایل‌های `knowledge/trends-2026.md` و `knowledge/site-audit-checklist.md` را به همه ایجنت‌ها به عنوان دانش مشترک بده.
5. اگر پلتفرم از فایل پیوست پشتیبانی می‌کند، پوشه `templates/starter` را هم برای ایجنت ۵ قرار بده.

> نکته: من به تنظیمات داخلی پلتفرم دسترسی ندارم؛ این پکیج را در قالب استاندارد (JSON و Markdown) آماده کرده‌ام تا با کپی و چسباندن قابل نصب باشد.

## نحوه استفاده (گام به گام)

1. **شروع پروژه:** حوزه کاری، نام برند (اختیاری)، لیست سایت‌های مرجع (اختیاری) و اهداف کسب‌وکار را بده.
2. **ایجنت ۱** ۱۰ تا ۲۰ سایت را بررسی و ماتریس بنچمارک را تحویل می‌دهد.
3. **ایجنت ۲** مشکلات UX و معماری اطلاعات را می‌سازد.
4. **ایجنت ۳** سیستم طراحی و لایوت‌ها را پیشنهاد می‌دهد.
5. **ایجنت ۴** حرکت‌ها و انیمیشن‌ها را مشخص می‌کند.
6. **ایجنت ۵** فایل‌های `index.html`، `styles.css` و `script.js` را می‌سازد و QA می‌کند.

جزئیات تحویل‌ها در `workflow.md` آمده است.

## اصول مشترک تیم

- **شاهد محور:** هر ادعا باید با لینک، اسکرین‌شات یا داده پشتیبانی شود.
- **کاربر اول:** زیبایی بدون وضوح و سرعت مجاز نیست.
- **حرکت با معنا:** هر انیمیشن باید راهنمایی، بازخورد یا روایت داشته باشد.
- **دسترسی‌پذیری پیش‌فرض:** کنتراست WCAG 2.2 AA، فوکوس قابل‌مشاهده، و پشتیبانی از `prefers-reduced-motion`.
- **ریسپانسیو از موبایل:** طراحی mobile-first با `clamp()`، CSS Grid و container queries.
- **سبک‌بودن:** فقط `transform` و `opacity` انیمیت شوند و از کتابخانه سنگین بی‌دلیل استفاده نشود.
