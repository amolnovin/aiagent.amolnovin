# چک‌لیست بررسی سایت (۱۰۰ امتیاز)

هر آیتم از ۰ تا ۵ امتیاز می‌گیرد. مجموع × ۲ = امتیاز از ۱۰۰ (در هر بخش، وزن مشخص شده).

## ۱. اولین تأثیر و hero (وزن ۱۵)
- [ ] پیام اصلی در ۵ ثانیه روشن است
- [ ] یک CTA اصلی دیده می‌شود
- [ ] تصویر یا ویدیوی hero مرتبط و بهینه است
- [ ] تیتر بیش از حد شلوغ نیست

## ۲. ناوبری و معماری اطلاعات (وزن ۱۵)
- [ ] منوی اصلی حداکثر ۷ آیتم دارد
- [ ] مسیر رسیدن به محصول یا خدمت در ۳ کلیک است
- [ ] breadcrumb یا مسیر مکان کاربر مشخص است
- [ ] جستجو (در صورت نیاز) در دسترس و قابل فهم است
- [ ] منو در موبایل (همبرگر یا tab bar) درست کار می‌کند

## ۳. CTA و تبدیل (وزن ۱۰)
- [ ] CTA اصلی در بالای صفحه و پس از هر بخش مهم تکرار شده
- [ ] متن CTA فعل و مشخص است (مثلاً «رزرو کنید» نه «کلیک کنید»)
- [ ] فرم‌ها کوتاه و با برچسب دائمی هستند
- [ ] نشانه‌های اعتماد نزدیک CTA قرار دارند

## ۴. ریسپانسیو (وزن ۱۰)
- [ ] در ۳۷۵px بدون اسکرول افقی است
- [ ] اهداف لمسی حداقل ۴۴×۴۴px هستند
- [ ] متن در موبایل خوانا است (بدون زوم)
- [ ] تصاویر و جدول‌ها در موبایل مناسب‌سازی شده‌اند

## ۵. تایپوگرافی و رنگ (وزن ۱۰)
- [ ] حداکثر ۲ خانواده فونت
- [ ] سلسله‌مراتب عنوان‌ها واضح است
- [ ] کنتراست متن ≥ ۴.۵:۱
- [ ] رنگ‌ها بیش از حد تعداد نیستند و با برند هماهنگ‌اند

## ۶. حرکت و تعامل (وزن ۱۰)
- [ ] انیمیشن‌ها معنادار هستند (راهنمایی، بازخورد، روایت)
- [ ] مدت انیمیشن کوتاه است (۱۵۰ تا ۶۰۰ms)
- [ ] `prefers-reduced-motion` پشتیبانی شده است
- [ ] محتوا فقط با انیمیشن ظاهر نمی‌شود

## ۷. دسترسی‌پذیری (وزن ۱۵)
- [ ] فوکوس کیبورد قابل‌مشاهده است
- [ ] ساختار heading منطقی است (یک h1)
- [ ] تصاویر alt دارند
- [ ] فرم‌ها برچسب دارند و خطاها واضح‌اند
- [ ] ویدیوها زیرنویس یا متن جایگزین دارند

## ۸. عملکرد (وزن ۱۰)
- [ ] LCP ≤ ۲.۵s
- [ ] INP ≤ ۲۰۰ms
- [ ] CLS ≤ ۰.۱
- [ ] تصاویر فرمت مدرن (WebP/AVIF) و lazy-load دارند

## ۹. اعتماد و محتوا (وزن ۵)
- [ ] اطلاعات تماس و آدرس واضح است
- [ ] نظرات یا گواهی‌ها واقعی و قابل‌راستی‌آزمایی هستند
- [ ] سیاست حریم خصوصی و شرایط در دسترس است

## ۱۰. تمایز و تازگی (وزن ۵)
- [ ] هویت بصری قابل‌تشخیص است
- [ ] از روندها استفاده شده ولی کپی نیست
- [ ] محتوای بصری واقعی (عکس، ویدیو، نمونه‌کار) دارد
